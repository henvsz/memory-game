# Jogo da Memória

Jogo da memória feito com HTML, CSS e JavaScript puros, sem bibliotecas.

## Funcionalidades

- 16 cartas (8 pares) embaralhadas a cada partida
- Contador de jogadas e cronômetro
- Recorde salvo no navegador (`localStorage`)
- Layout responsivo e acessível (teclado e leitores de tela)

## Como jogar

Vire duas cartas por vez. Se forem iguais, elas ficam reveladas. Encontre todos os pares com o menor número de jogadas.

## Como executar

Baixe o projeto e abra o arquivo `index.html` no navegador.

Para publicar no GitHub Pages: **Settings → Pages → Deploy from a branch → main / root**.

## Tecnologias

HTML5, CSS3 e JavaScript (ES6).
